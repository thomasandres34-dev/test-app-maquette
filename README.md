# TCMV — aperçu HTML

Maquette interactive (pas l'app finale Lovable). Connexion automatique : Thomas (admin).

## Mettre en ligne sur GitHub Pages
1. Crée un dépôt (ex. `tcmv-apercu`) et dépose **tout le contenu de ce dossier** à la racine.
2. Réglages du dépôt › Pages › Source : `Deploy from a branch` › branche `main` › dossier `/ (root)`.
3. L'aperçu est en ligne après 1–2 min sur `https://<ton-compte>.github.io/tcmv-apercu/`.

- `index.html` : page d'accueil (app dans un cadre iPhone + lien Espace Coach). Sur téléphone : plein écran.
- Données (séances, comptes, réglages) = stockées dans le navigateur de chaque visiteur.
